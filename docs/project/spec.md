# 会社向け案件原価と利益管理アプリ 仕様書

版：0.3 提案版  
作成日：2026年11月6日  
対象：制御設計、ソフトウェア開発、盤製作、現地調整などを案件単位で行う会社  
今回の改訂：受注前の案件見込と受注後の完了見込を分け、確度・時期・予算比較・月次集計・履歴管理を追加

## 1 目的と位置づけ

案件ごとの売上、工数、材料費、外注費、旅費などを集め、予算に対してどこで原価が増え、完了時にいくら利益が残る見込みかを確認する。担当者は日々の実績を簡単に入力し、案件責任者は予算超過や追加請求の必要性に早く気づけるようにする。

受注前から案件見込を登録し、どの案件が、いつ、どの程度の確度で受注・売上につながるかも確認する。本書では「案件見込」を営業段階の見込み、「完了見込」を受注済み案件の最終原価・利益の見込みとして区別する。

最初の版は、案件別の原価管理を中心にする。会社全体の会計、給与計算、税務申告、正式な収益認識の判定までを置き換えない。案件直接利益の合計を、会社の営業利益や税引後利益として表示しない。

作成方針は、Bantoをベースに会社用アプリを新たに作ることとする。既存のBanto-businessは個人用であり、会社用とはアプリと業務データを分ける。個人用をそのまま会社の共用環境に切り替える前提にはしない。

この作成方針以外の機能・運用の詳細は提案であり、すべてが承認済み要件という意味ではない。また、実装済み機能を示すものではない。MVPは最初に運用可能にする最小構成を指す。会社の具体的な会計方針、承認者、締め日は第14章で確定する。

## 2 初期リリースの範囲

### 2.1 提案するMVP

1. 受注前の案件見込・確度・予定時期と、見積額・受注額・売上計上額の分離管理。
2. 工程別・費目別の予算と、当初予算・承認済み変更の保存。
3. 社員の工数入力、適用日つき時間原価単価による労務原価計算。
4. 材料費、外注費、旅費などの案件直接費入力。
5. 発注済み未実績分と、今後必要な原価の見込み管理。
6. 予算・実績・完了見込の比較、月次売上見通し、案件別・顧客別・月別の集計。
7. 申請・承認・差戻し、月次締め、訂正履歴。
8. 役割・担当案件によるアクセス制御、CSV出力。

初期版は単一会社・円建てを対象とする案とする。金額は原則税抜で比較するが、税区分や端数処理を含む正式な運用は導入前に決める。

### 2.2 後から追加する機能

- 給与・勤怠・会計・請求・購買システムとの自動連携。
- 在庫数量、棚卸、仕掛品評価、固定資産・減価償却の本格管理。
- OCRによる領収書読取り、承認経路の自由な多段設定。
- 外貨、複数法人、連結、詳細な資金繰り。
- 間接費の自動配賦と複数シナリオの比較。
- 請求書・発注書の発行や外部への自動送信。
- 工事進行や履行義務に基づく売上計上の自動判定。

### 2.3 Bantoをベースにする範囲

Bantoの設計・画面・共通処理などを再利用できるか調査し、会社用の案件原価管理に必要な機能を追加・調整する。Bantoの既存機能、対象リポジトリ、API、認証方式、データ構造は本書では未確認であり、特定機能がすでに存在するとは断定しない。

- 個人用Banto-businessと会社用アプリを区別し、会社の案件・原価・利用者・権限を会社用として管理する。
- 個人用データを会社用の検索・集計・CSV・画面に混入させず、会社用の利用権限から個人用データへアクセスできないようにする。
- 個人用データの移行・同期・共有は初期要件に含めない。必要になった場合は対象データ、利用目的、閲覧者、移行・同期方式を別途決める。
- コードを共通化する範囲、リポジトリの構成、認証の共通化、DBの物理分離または論理分離、デプロイ先・構成は未決とする。アプリと業務データを分ける方針だけで、別サーバーや別DBの採用まで確定したことにはしない。
- 個人用Banto-businessとの統合や接続を前提条件にせず、会社用単独で必要な業務を行える構成を検討する。

既存資産を確認してから再利用範囲と不足機能を整理し、会社用の構成案を決める。既存の個人用環境に対する変更、データ移行、本番反映は本書の作成だけでは実施しない。

## 3 用語と金額の扱い

### 3.1 売上に関する区別

| 項目       | 意味                                                     | 利益計算への使用                               |
| ---------- | -------------------------------------------------------- | ---------------------------------------------- |
| 見込受注額 | 未受注案件について予想する契約金額。正式見積前も入力可能 | 営業見込みに使用。受注額・売上実績には含めない |
| 見積額     | 顧客に提案している金額。版を保存する                     | 受注前の見積利益に使用                         |
| 受注額     | 契約・注文などで確定した金額                             | 完了見込利益の基準に使用                       |
| 売上計上額 | 会社の方針に従い経理が承認した計上額                     | 管理用実績直接利益に使用                       |
| 請求額     | 顧客に請求した金額                                       | 参考情報。売上へ自動加算しない                 |
| 入金額     | 実際に回収した金額                                       | 参考情報。利益へ加算しない                     |

見込受注額、見積額、受注額、売上計上額、請求額、入金額を合算しない。同じ営業案件の見込受注額と見積額は別の売上ではない。受注変更は差額と根拠を記録し、最新版の受注額を作る。承認前の追加工事・値上げ交渉は「未確定追加売上」として分離し、標準の完了見込利益へ含めない。

請求・入金の明細管理はMVPの必須要件に含めない。参考値を持つ場合も売上計上とは別の項目にする。

### 3.2 原価に関する区別

| 項目           | 内容                                           |
| -------------- | ---------------------------------------------- |
| 労務原価       | 承認済み工数に時間原価単価を掛けた管理上の原価 |
| 材料費         | 案件に使用・帰属させる部材、機器、消耗品など   |
| 外注費         | 外部に委託した設計、開発、製作、施工、調整など |
| 旅費交通費     | 案件に直接ひもづく交通費、宿泊費など           |
| その他直接費   | 案件専用の運搬、レンタル、試験、ライセンスなど |
| 共通費・間接費 | 複数案件や会社全体に関わる費用。直接費と分ける |

会社が給与として支払う額と、工数から求める労務原価は一致するとは限らない。時間原価単価に含めた費用を、共通費として重ねて配賦しない。

発注・請求・支払は同じ取引の異なる段階である。外注の発注額を実績に加え、請求書登録でもう一度加算することを禁止する。

### 3.3 予算と実績と見込の区別

| 区分     | 役割                                                       | 更新したときの扱い                         |
| -------- | ---------------------------------------------------------- | ------------------------------------------ |
| 案件見込 | 受注前の金額、確度、予定時期を示す                         | 営業見込みの最新版を更新し、変更履歴を残す |
| 承認予算 | 受注後の原価管理で守る計画・比較基準                       | 正式な変更承認がある場合だけ改版する       |
| 実績     | 発生・承認された工数、費用、売上を示す                     | 原記録と訂正手順に従って更新する           |
| 完了見込 | 基準日までの実績と、それ以降に必要な原価から着地を予測する | 予算とは別の見込版として保存する           |

予算超過を予測しただけで予算を引き上げない。予算と見込は比較対象であり、合計するものではない。本書の「見込粗利」は共通費配賦前の「完了見込直接利益」を指し、会計粗利とは区別する。

## 4 利用者と権限

| 役割           | 主な操作                                                   | 閲覧範囲の初期案                     |
| -------------- | ---------------------------------------------------------- | ------------------------------------ |
| 入力担当者     | 自分の工数・経費を入力し申請                               | 自分の記録、割当案件の必要な基本情報 |
| 営業担当者     | 案件見込、確度、見込受注額、予定時期を更新                 | 担当する営業案件と必要な原価見積情報 |
| 案件責任者     | 案件予算・残作業見込みを更新し、担当案件の実績を確認・承認 | 担当案件の売上・原価・利益           |
| 経理担当者     | 原価単価、売上計上、費用確認、月次締め、訂正承認           | 業務上必要な全案件と原価情報         |
| 経営者・管理者 | 全社・案件別の経営状況を確認                               | 全案件の集計と必要な明細             |
| システム管理者 | 利用者・権限・マスタを管理                                 | 金額・単価の閲覧は別権限で付与       |

- 個人別の時間原価単価は経理などに限定する。案件責任者には原則として労務原価の集計値を見せ、個人別単価や給与情報を見せない。
- 一人しか作業していない工程などでは、集計値から単価を推測できる。必要なら工数と金額の同時表示を制限する。どこまで秘匿するかは導入前に決める。
- 兼務は可能とする。自分が申請した記録の自己承認は初期案では不可とし、小規模運用での例外を設定する場合は履歴を残す。
- 画面だけでなく、API、CSV、検索結果、明細の直接URLにも同じ権限を適用する。
- 会社用の所属・役割と個人用の利用権限を混同しない。認証基盤を共通化する場合も、会社用への所属と権限は明示的に付与し、個人用の権限をそのまま引き継がない。

## 5 案件と予算

### 5.1 案件台帳

共通の必須項目は案件ID、案件名、顧客、責任者、状態とする。受注前の予定日は未定を許可し、受注後は予定開始日・完了日を必須にする。任意項目として、受注番号、顧客担当窓口、部門、備考、関連資料への参照を持つ。

状態は「引合 → 見積中 → 交渉中 → 受注 → 進行中 → 作業完了 → 精算完了」を基本とし、失注・中止・保留も選べる。作業完了と精算完了を分け、作業後の請求到着や手直し費用を漏らさない。

未承認実績、未実績発注残、残作業見込み、未処理の売上差額が残る場合、精算完了にはできない。不要になった残額を解消する際は、理由と承認を残す。

### 5.2 工程

初期候補は「設計」「ソフト開発」「製作」「試験」「現地調整」「管理・打合せ」とする。案件ごとに必要な工程だけ使用できる。案件内の手直しは理由を分類し、当初作業と区別して集計できるようにする。

細かすぎる作業分解を必須にせず、案件・工程・費目の3軸で開始する。社内会議、教育、営業、待機など案件に直接帰属しない時間は共通活動へ記録し、無理に案件へ付け替えない。

### 5.3 予算

- 労務費は予定工数と予算用単価から計算する。材料・外注・旅費・その他は予定金額を登録する。
- 当初承認予算を基準として保存し、変更後も上書きで失わない。
- 変更予算は版番号、変更理由、承認者、承認日を持つ。
- 「当初予算」「現在の承認予算」「実績」「完了見込」を並べる。
- 見積作成中の案は編集可能とし、承認済み予算や受注額を無断で変えない。

### 5.4 受注前の案件見込

案件ごとに、見込受注額、営業段階、受注確度、受注予定月、作業開始・完了予定月、売上計上予定月または月別配分、根拠、次の確認事項、最終確認日を持つ。金額・確度・時期が不明な場合は「未設定」「未定」とし、0円・0%や当月に置き換えない。

入力中の下書きと担当者が確認した採用版を分け、標準集計は案件ごとの最新採用版を使う。未設定を含む場合は採用版でも不足ありと表示し、計算可能な範囲と除外分を分ける。

受注確度は、受注が成立する可能性についての担当者判断であり、作業進捗率や売上計上率ではない。初期案として引合10%、見積中30%、交渉中50%、内示あり80%などの目安を設け、実際の基準は会社で決める。未受注では0〜99%の範囲で理由つき変更を可能とし、内示だけでは受注済みにしない。受注成立の確認後に受注済みへ切り替え、確度100%相当として確定受注側で扱う。

- 同じ引合の複数見積版・代替案は一つの案件にまとめ、集計対象の見込を一つだけ選ぶ。
- 見込受注額は見積額を初期値として使えるが、値引き予想などで異なる場合は理由を残す。見積の更新で担当者の見込を無断で上書きしない。
- 受注予定月と売上計上予定月を別々に持つ。受注した月に全額売上となるとは限らない。
- 原価概算がある場合は「受注成立時の原価概算」と「受注成立時の見込直接利益」を参考表示する。概算未入力を原価0円として扱わない。
- 受注前に発生した営業工数・費用も実績として扱い、確度を掛けて減らさない。営業共通費か案件帰属かは会社方針で決め、受注転換で実績をコピー・再計上しない。
- 失注・中止は現時点の見込集計から除外し、履歴と発生済み実績は残す。保留案件は標準集計から除外し、条件を指定した場合のみ別枠で表示する。

### 5.5 受注への転換と売上予定

受注時には同じ案件IDの状態を切り替え、受注日、確定金額、根拠を記録する。直前の案件見込を履歴に保存し、現時点の未受注見込から除外する。見込金額を実績売上へ直接振り替えず、確定受注額と売上計上予定を別に設定する。

部分受注は受注済み範囲と未受注範囲へ分割し、元の見込を集計対象外にする。範囲・金額・明細の帰属を指定し、受注分が未受注見込にも残らないようにする。既存案件の追加作業は元案件にひもづく追加見込として扱い、成立時は受注変更へ転換する。同じ追加分を営業案件と受注変更の両方へ計上しない。

受注済み案件では、確定受注額から累計売上計上額を差し引いた未計上残を、今後の売上計上予定月へ配分する。月別予定額と時期未定額の合計が未計上残に一致することを確認する。受注額を超える計上やマイナス残は不整合として確認し、黙って0円へ丸めない。実績売上を計上したら、対応する予定額を消し込む。

売上予定は営業・管理上の予測であり、自動で会計売上を計上する機能ではない。将来の計上時期は経理の方針に合わせて確認する。

## 6 実績入力

### 6.1 工数

入力項目は、作業日、担当者、案件または共通活動、工程、作業時間、作業内容、手直し区分とする。時間は分単位で保持し、画面は時間表示もできる。初期案は15分単位入力とし、会社の運用で変更できるようにする。

1日の合計が24時間を超える入力、ゼロ以下の作業時間、担当外案件への入力を禁止する。所定時間との差は警告として扱い、残業・短時間勤務などを誤って拒否しない。同じ日・案件・工程の重複候補は警告するが、複数回の作業自体は許可する。

工数は「下書き → 申請 → 承認」または「差戻し」で管理する。標準レポートは承認済みだけを実績集計する。未申請・未承認の件数と時間を別に表示し、入力不足をゼロ原価と誤認させない。

### 6.2 時間原価単価

時間原価単価の算定案は次のとおりとする。

**時間原価単価 = 対象期間の人件費相当額 ÷ 同期間の基準時間**

対象費用の候補は給与、賞与、会社負担の社会保険など。基準時間は年間所定時間か直接作業可能時間かを選び、会社で統一する。後者を使うと間接時間の負担を単価に含める可能性があるため、共通費配賦との重複を確認する。

MVPでは計算済みの単価を経理が登録する。給与明細や個別給与の取込みは必須にしない。個人別・等級別・一律のどれを採用するかは未決とする。

- 単価に適用開始日・終了日・版を持たせ、作業日の単価を使う。
- 適用期間の重複や、必要な単価が未登録の状態を検出する。
- 単価未設定の工数を0円として確定しない。原価未確定と表示する。
- 承認時に適用単価と計算結果を保存し、後日の単価変更で過去実績を自動更新しない。
- 過去修正が必要なら、対象期間・理由を指定した訂正として再承認する。
- 残業割増、休日出勤、出張移動時間の扱いは会社で決める。給与制度から自動推定しない。

### 6.3 材料費と外注費

明細には案件、工程、費目、取引先、内容、管理計上日、税抜額、税区分、税込額、証憑番号、確認者を持つ。発注にひもづく場合は発注IDも保持する。

発注記録には発注額、取消額、実績化済み額、未実績残を持たせる。分納・分割検収に対応し、実績化の都度、対応する残額を減らす。請求額が発注額を超える場合は差額の理由と承認を求める。

管理計上日は、材料の使用日、外注作業の検収日など会社で決めた基準に従う。請求書の到着日・支払日だけで自動決定しない。請求未着でも金額を見積計上する場合は「仮計上」と明示し、請求確定時は元の仮計上を置き換える訂正とする。

在庫を扱わないMVPでは、案件へ帰属させる額を手入力する。まとめ買い、在庫払出し、別案件への振替を行うときは配分額・根拠を残し、配分合計が元の費用を超えないようにする。

### 6.4 旅費とその他直接費

案件、日付、支出者、費目、金額、証憑番号または証憑参照、内容を登録する。一つの出張が複数案件に関わる場合は明示した基準で分割し、合計を元の支出額に一致させる。

立替経費の精算額と会社カードの引落額を別々の原価として加算しない。支払方法は費用の属性であり、支払時に新しい原価を作らない。

### 6.5 今後の原価見込み

案件責任者は、残工数、今後の材料・外注・旅費・その他を更新する。残工数は見込み用単価を掛けて金額にする。

未実績発注残は将来原価の内数とする。画面では「発注済み未実績」と「それ以外に必要な見込み」を分けて入力し、同じ費用を両方へ入れない。不要になった発注や、値上がりが見込まれる発注は見直し理由を残す。

### 6.6 完了見込の版と更新

完了見込は基準日、版、対象の受注額・予算版、基準日までの実績原価、残工数・残費用、適用単価、完了予定日、更新理由、更新者、確認者を一組として保存する。下書きと採用版を分け、標準レポートは最新の採用版を使う。採用の確認者と頻度は会社で定める。

1. 基準日までの承認済み実績を取り込み、未登録・未承認・仮計上を確認する。
2. 現在の発注残を照合し、前回以降に実績化した分を残見込みから外す。
3. 前回以降の作業実績を見て、残工数を再見積りする。単に前回の残工数と最新実績を足さない。
4. 追加作業、手直し、値上がり、納期変更を反映し、前回見込との差額と理由を確認する。
5. 採用版を保存し、当初予算・現在予算・前回見込・今回見込を比較する。

採用版の実績と残見込みは同じ基準日の組で保持する。後から実績が増えても、古い残見込みを足して完了見込原価を自動増額しない。最新実績は別列に表示し、「見込更新要」の表示で再見積りを促す。基準日以前の実績が訂正された場合も元の版を残して、新しい見込版で反映する。

基準日までに発生しているが未登録の原価は、可能なら仮計上して承認する。金額や承認がそろわない場合は「暫定・不足あり」と表示し、確定した見込として扱わない。見込みを修正しただけで承認予算、実績、受注額を書き換えない。

## 7 計算と表示

### 7.1 基本式

| 指標                 | 計算式                                                 |
| -------------------- | ------------------------------------------------------ |
| 労務原価             | 承認済み作業時間 × その作業日に適用する時間原価単価    |
| 実績直接原価         | 労務原価 + 材料費 + 外注費 + 旅費交通費 + その他直接費 |
| 管理用実績直接利益   | 売上計上額 − 実績直接原価                              |
| 管理用実績直接利益率 | 管理用実績直接利益 ÷ 売上計上額 × 100                  |
| 残原価見込み         | 発注済み未実績分 + 未発注費用の見込み + 残労務原価     |
| 完了見込原価         | 実績直接原価 + 残原価見込み                            |
| 完了見込直接利益     | 現在の確定受注額 − 完了見込原価                        |
| 完了見込直接利益率   | 完了見込直接利益 ÷ 現在の確定受注額 × 100              |
| 原価予算差異         | 実績直接原価 − 現在の承認原価予算                      |
| 完了見込超過額       | 完了見込原価 − 現在の承認原価予算                      |

完了見込の式は同じ採用版・基準日の実績と残見込みで計算する。「最新実績」と「前回採用時の残見込み」を混ぜない。前回見込との差異は今回の完了見込原価から前回の完了見込原価を引いて求め、受注変更による利益増減とは分けて説明する。

原価予算差異・完了見込超過額はプラスが超過、マイナスが予算内を意味する。現在の実績が予算内でも、残作業を含めると超過する案件を把握できるようにする。

売上計上額が0円の場合の利益率は0%にせず「算出不可」とする。受注額が0円または未確定の場合の完了見込利益率も同様とする。入力不足、単価不足、未承認実績がある場合は集計の確定度を表示する。

### 7.2 途中案件の読み方

管理用実績直接利益は、会計上の売上原価や仕掛品評価まで調整した会計粗利とは限らない。原価が先に発生し、売上が検収後に計上される案件では、途中の実績直接利益がマイナスでも最終赤字を意味しない。

進行中案件には必ず「途中実績」と表示し、実績直接利益と完了見込直接利益を併記する。月次の管理集計にも同じ注記を付け、年度をまたぐ案件は当月・当期・案件累計を切り替えられるようにする。

### 7.3 共通費と会社利益

MVPの標準指標は共通費配賦前の案件直接利益とする。共通費配賦を採用する場合は、配賦前・配賦額・配賦後を別列に表示し、元の直接原価を書き換えない。

配賦対象期間、対象費用、配賦対象案件、基準、端数処理、未配賦額を保存する。候補は直接工数比、労務原価比、売上比などで、採用基準は未決とする。単価に含まれる人件費や間接時間を再配賦しない。

配賦後の利益も管理用であり、会計上の営業利益・経常利益・当期純利益とは区別する。会計との照合には、未配賦共通費、工数原価と実人件費の差、仕掛・在庫、減価償却、その他損益、計上時期差などの調整が必要になる。

### 7.4 数値の保持と丸め

工数は整数分、金額は固定小数で保持し、浮動小数の誤差を避ける。初期案は明細ごとの労務原価を円単位で四捨五入し、その保存値を合計する。利益率は小数第1位表示とし、集計利益率は利益合計 ÷ 売上合計で計算する。案件ごとの利益率を単純平均しない。

税額・端数処理は証憑単位のルールに合わせる。税込額から税抜額を逆算する場合や、非課税・不課税・免税・控除対象外の扱いは経理確認のうえ確定する。

### 7.5 案件見込と月次売上見通しの集計

| 指標             | 計算・集計方法                                                             |
| ---------------- | -------------------------------------------------------------------------- |
| 未受注見込総額   | 有効な未受注案件の見込受注額を合計。確度は掛けない                         |
| 確度加重見込額   | 各未受注案件の見込受注額 × 受注確度を合計                                  |
| 受注予定月別見込 | 受注予定月で未受注見込総額と確度加重見込額を別々に集計                     |
| 受注済み売上予定 | 確定受注の未計上残について、対象月に配分した額を合計                       |
| 未受注の売上見込 | 未受注案件の対象月売上予定額 × 受注確度を合計                              |
| 月次売上見通し   | 対象月の計上済み売上実績 + 同月の受注済み売上予定 + 同月の未受注の売上見込 |

受注予定月別の金額と売上予定月別の金額を足し合わせない。月次売上見通しは三つの内訳を分けて表示し、確定売上や会社の会計損益として表示しない。計上済み売上を受注済み売上予定に残さず、受注済み案件を未受注見込に残さない。

受注済み案件の未確定追加分を含める場合は、追加差額だけを未受注側の別枠に表示する。元の確定受注額全体へ再度確度を掛けたり、追加差額を受注済み側にも加算したりしない。

未受注の月別売上予定と時期未定額は見込受注額に一致させる。時期未定は独立した列・一覧へ出し、任意の月に配分しない。金額・確度の不足がある場合も、確度加重計算から除いた件数と理由を表示する。

確度加重見込額は案件群を見渡すための参考値であり、入金の保証や発注判断の根拠に単独で使わない。未受注の原価・粗利を確度加重して会社損益へ合算する機能は初期版に含めず、案件ごとの受注成立時の概算として分離表示する。

案件見込と月次売上見通しは確認時点のスナップショットを保存し、現在の見込みと前月末時点の見込みを比較できるようにする。案件の受注・失注・延期や確度変更で過去の報告値を書き換えない。表示中の時点における状態・金額・確度・予定月を使って再現する。

複数案件の完了見込を集計するときは各案件の採用版と基準日を保持し、月次確認日より古い見込を含む場合は件数と対象案件を示す。新しい実績と古い残見込みを組み合わせて集計日だけを最新に見せない。

## 8 入力から月次確認までの流れ

1. 営業担当者が案件見込、確度、受注予定月・売上予定月を登録し、受注後に責任者が工程と当初予算を設定する。
2. 経理または指定承認者が予算・単価・売上管理の前提を確認する。
3. 担当者が日々の工数・経費を入力し、週次など会社で決めた頻度で申請する。
4. 案件責任者が担当案件の内容を確認し、承認または理由つきで差し戻す。
5. 経理が材料・外注・旅費などを証憑や発注と照合し、売上計上を承認する。
6. 営業担当者が未受注案件の確度・時期を、案件責任者が残工数・発注残・未発注費用を見直し、見込版を保存する。
7. 月末または所定締め日に、入力不足・仮計上・単価不足・不整合を確認して締める。
8. 経営者が受注見込・月次売上見通しと、受注済み案件の予算超過・低利益率・追加請求未確定・入力遅延を確認する。

締め後の直接編集は禁止する。経理権限による理由つき再開・再承認、または翌月調整のどちらを使うかを決め、元の値と訂正後の値を追跡可能にする。通常の訂正で記録を物理削除しない。

## 11 訂正と安全な運用

- 承認済み金額・工数の修正には理由と再承認を必須にする。
- 取消、返品、値引きは元明細と対応づけた調整として扱う。通常入力の負数とは区別する。
- 同時編集では版を確認し、後から保存した内容が他人の変更を黙って消さない。
- 送信の再試行で同じ工数・費用・売上が二重登録されない仕組みを設ける。
- 月次締め時点の数値を保存し、訂正後の最新値との違いを確認できるようにする。
- 案件見込の金額・確度・時期・状態と完了見込の変更前後を保存し、理由・更新者・確認者を追跡する。見込の改版で実績や承認予算を変更しない。
- バックアップと復元手順を設け、導入前に実際の復元確認を行う。保存期間、頻度、復旧目標は会社で決める。
- 認証、通信保護、操作ログを備える。原価単価や個人情報を一般ログへ出さない。
- 証憑参照や添付に独立した権限がある場合、アプリの利用権限だけで外部資料の閲覧権限まで付与しない。

## 12 計算例

### 12.1 制御盤と現地調整の案件

以下は仕様確認用の架空例。すべて税抜・円建てで、共通費配賦前とする。

| 項目         | 当初承認予算 | 現時点の実績 | 今後の原価見込み |  完了見込 |
| ------------ | -----------: | -----------: | ---------------: | --------: |
| 労務原価     |    1,000,000 |      700,000 |          500,000 | 1,200,000 |
| 材料費       |      900,000 |      800,000 |          200,000 | 1,000,000 |
| 外注費       |      500,000 |      300,000 |          200,000 |   500,000 |
| 旅費交通費   |      150,000 |       80,000 |           70,000 |   150,000 |
| その他直接費 |       50,000 |       20,000 |           30,000 |    50,000 |
| 合計         |    2,600,000 |    1,900,000 |        1,000,000 | 2,900,000 |

確定受注額は4,000,000円。労務単価は5,000円/時とし、当初200時間、実績140時間、残見込み100時間とする。

- 当初見込直接利益：4,000,000 − 2,600,000 = 1,400,000円、利益率35.0%。
- 完了見込直接利益：4,000,000 − 2,900,000 = 1,100,000円、利益率27.5%。
- 完了見込超過額：2,900,000 − 2,600,000 = 300,000円。
- 材料・外注の今後400,000円がすべて発注済みなら、未実績発注残は400,000円。この額は残原価見込み1,000,000円に含まれ、別途加算しない。

検収前で売上計上額が0円なら、管理用実績直接利益は−1,900,000円、実績利益率は算出不可と表示する。同じ画面に完了見込直接利益1,100,000円を示し、これだけで最終赤字と判断させない。

未確定の追加作業売上300,000円がある場合、確定前の標準受注額は4,000,000円のままとする。追加原価が残見込みに含まれているかも確認する。受注変更が確定し、追加原価を含む完了見込原価が2,900,000円のままであれば、受注額4,300,000円、完了見込直接利益1,400,000円、利益率32.6%となる。

### 12.2 発注と請求の重複防止

外注を500,000円で発注し、300,000円分を検収した場合、実績外注費は300,000円、未実績発注残は200,000円。後から同じ300,000円の請求書が届いても、実績外注費は600,000円にならない。検収時の仮計上と照合し、確定情報へ更新する。

### 12.3 共通費を配賦する場合

完了見込直接利益1,100,000円に、同じ対象期間・案件に対応する共通費配賦見込み200,000円を加える場合、配賦後見込利益は900,000円。配賦前の1,100,000円も残して表示し、会社の営業利益とは表示しない。

### 12.4 受注前の案件見込と月次売上見通し

未受注の案件Aは見込受注額3,000,000円、確度60%、11月受注予定、12月売上計上予定とする。未受注見込総額は3,000,000円、確度加重見込額は1,800,000円。11月の受注予定と12月の売上見込の両方に現れるが、二つを加算した3,600,000円を売上見込にはしない。

12月に別の受注済み案件Bで売上実績500,000円、未計上の売上予定1,000,000円がある場合、12月の売上見通しは500,000 + 1,000,000 + 1,800,000 = 3,300,000円となる。

案件Aが2,800,000円で正式受注し、全額が12月売上予定となった場合、未受注側の1,800,000円を外し、受注済み売上予定に2,800,000円を計上する。12月売上見通しは500,000 + 1,000,000 + 2,800,000 = 4,300,000円となり、以前の見込を足した6,100,000円にはならない。受注前の報告スナップショットは3,300,000円のまま保持する。

### 12.5 完了見込を更新する場合

第12.1節の前回採用版は実績原価1,900,000円、残原価1,000,000円、完了見込原価2,900,000円である。その後300,000円分が実績化し、最新実績が2,200,000円になっても、古い残原価1,000,000円をそのまま足した3,200,000円を新しい完了見込とはしない。

残原価を確認し、前回残額から実績化分300,000円を外し、新たな追加原価100,000円を見込む場合、今回残原価は800,000円。今回完了見込原価は2,200,000 + 800,000 = 3,000,000円、確定受注額4,000,000円に対する見込直接利益は1,000,000円、利益率25.0%となる。前回から原価100,000円増、当初予算2,600,000円に対して400,000円超過であり、当初予算自体は変わらない。
